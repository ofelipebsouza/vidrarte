# VIDRARTE — Site institucional

Site institucional estático da VIDRARTE, vidraçaria em Santos/SP.

## Conteúdo

- `index.html`: página completa e metadados locais.
- `style.css`: identidade visual responsiva e navegação móvel.
- `script.js`: menu acessível e orçamento por WhatsApp.
- Imagens WebP: referências ilustrativas de box e manutenção.
- `robots.txt` e `sitemap.xml`: arquivos básicos de indexação.

## Publicação na Vercel

Importe o repositório como projeto estático, com a raiz como diretório e sem comando de build. As fotografias são ilustrativas e não representam obras executadas pela VIDRARTE.
